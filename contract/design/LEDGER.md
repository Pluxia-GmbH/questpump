# Licence ledger

Generated by `tools/ledger.py` from `contract/design/ledger.json` (fonts, licence texts, the voice, own art), `contract/design/sound/sounds.json` with `receipts.json` (sounds), `tools/voice/clips.json` (the voice's takes), `contract/figures/figures.json`, `contract/figures/watch/pack.json` and `QuestPump_FigArmor/pack.json` (the move figures) and `contract/design/icons.json` (the app icons); never hand-edited. Every font, licence text, sound, voice take, image, film and icon the apps, the desktop app and the site ship (Android's vector drawables included) has a row, a byte-for-byte copy of a listed file the row of its original; `tools/ledger.py --check` finds each such file in the shipped roots (the apps' sources, `helper/dist`, `helper/src-tauri/icons`, `site/public`, what `helper/src-tauri/tauri.conf.json` bundles) and the figure folders and proves its digest. The art drawn from `contract/design/art/*.svg` ships as code and is Pluxia's own: each file has its row under Own art.
